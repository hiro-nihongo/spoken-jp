# New System Spoken Japanese（学生用ページ）

## ファイルのやくわり

| ファイル | やくわり |
|---|---|
| `index.html` | 課のいちらん |
| `lesson.html` | 課のページ（`lesson.html?id=6-1` のように開く） |
| `app.css` / `app.js` | 見た目とうごき（ふだんは さわらない） |
| `lessons/index.js` | 課のいちらんのデータ |
| `lessons/6-1.js` | 6か-1 の会話データ |
| `audio/6-1P.mp3` | 6か-1 の会話全体の音声 |

## 文を直すとき

`lessons/6-1.js` を開いて、`ja:`（日本語）、`rd:`（タイ文字の読み方）、`th:`（タイ語訳）の `'...'` の中を書きかえます。

- `{漢字|よみ}` … ふりがな（例：`{今日|きょう}`）
- `[[よ]]` … 強調（太字＋下線）
- `w: 0` … 話す人の番号（`speakers` の順。0 が1人目で右がわ）

## 新しい課を足すとき

1. `lessons/6-1.js` をコピーして、`lessons/7-1.js` のように名前を変え、中身を書きかえる。
2. `lessons/index.js` に1行足す。
3. 音声を `audio/7-1P.mp3` の名前で入れる（P＝ていねい、N＝ふつう、R＝もっとていねい）。

## 音声

- `audio/6-1P-00.mp3` … 会話ぜんたい（「ぜんぶ きく」）
- `audio/6-1P-01.mp3`〜`15.mp3` … 1行ずつ（ふきだしをタップ、「この文を きく」）
- どれもモノラル・160kbps。スマホのスピーカーで聞き取りやすいように、音量と声の高い部分を整えてあります。
- 1行の音声を差しかえるときは、同じ名前のファイルで上書きするだけです。
- `cues:` は、ぜんたいの音声の中で各行が何秒から何秒か、です。「ぜんぶ きく」のときに、いま話している文に枠を付けるのに使います。
